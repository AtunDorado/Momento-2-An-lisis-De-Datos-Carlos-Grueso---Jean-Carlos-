# Dashboard Momento 2 · Frutales Valle del Cauca

```
pip install -r requirements.txt
streamlit run app.py
```

- `preparacion.py`: limpieza de datos (también se puede correr sola con `python preparacion.py`).
- `app.py`: dashboard. Importa `preparacion.py` y lee `frutales.csv`, sin pasos manuales.
- `captura_*.png`: respaldo de la demo.
- Fuente: datos.gov.co, Ministerio de Agricultura y Desarrollo Rural (descarga 28-sep-2026).
